# Сапер (цветной)

Классическая игра «Сапер» в цветном консольном исполнении на 8 языках программирования.  
Реализованы все основные механики: открытие клеток, установка флагов, автоматическое открытие пустых областей, таймер, счётчик мин, настраиваемые уровни сложности и сохранение рекордов.

## Особенности
- Три уровня сложности: лёгкий (9×9, 10 мин), средний (16×16, 40 мин), сложный (30×16, 99 мин).
- Цветное отображение цифр, флагов и мин с помощью ANSI-кодов.
- Первый клик всегда безопасен (мины генерируются после первого хода).
- Автоматическое открытие клеток без мин.
- Возможность ставить/снимать флаги.
- Таймер игры и счётчик оставшихся мин.
- Сохранение лучшего времени для каждого уровня в локальном файле (рекорды).
- Интуитивное управление: ввод координат `строка столбец` (например, `a1`), с префиксом `f` для флага.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты.

### Запуск на разных языках

1. **Python**  
   Запуск: `python minesweeper.py`

2. **JavaScript (Node.js)**  
   Установка: `npm install readline-sync chalk` (опционально, можно использовать встроенный `readline` и ANSI).  
   Запуск: `node minesweeper.js`

3. **Go**  
   Запуск: `go run minesweeper.go`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run --release`

5. **Java**  
   Сборка: `javac Minesweeper.java`  
   Запуск: `java Minesweeper`

6. **C# (.NET Core)**  
   Запуск: `dotnet run`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o minesweeper minesweeper.cpp`  
   Запуск: `./minesweeper`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc Minesweeper.kt -include-runtime -d minesweeper.jar`  
   Запуск: `java -jar minesweeper.jar`

## Использование
После запуска выберите уровень сложности: `1` (лёгкий), `2` (средний), `3` (сложный).  
Игровое поле отображается с буквами столбцов (a–…) и цифрами строк (1–…).  
Ввод команд:
- `a1` – открыть клетку на строке 1, столбце a.
- `f a1` – поставить/снять флаг на клетке a1.
- `q` – выход.

Цветовая схема:
- Цифры: 1 – синий, 2 – зелёный, 3 – красный, 4 – тёмно-синий, 5 – тёмно-красный, 6 – бирюзовый, 7 – чёрный, 8 – серый.
- Флаг – жёлтый (`⚑`).
- Мина – красная (`💣`).
- Неоткрытая клетка – тёмно-серый фон.
- Открытая – светло-серый фон.
